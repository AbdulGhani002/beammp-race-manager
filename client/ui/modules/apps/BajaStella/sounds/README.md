# Stella III EVO — Sound Files

Place the following sound files in this folder:

| File                     | Description                                      |
|--------------------------|--------------------------------------------------|
| `speed_zone_entry.mp3`   | Beeps repetidos al entrar a una Speed Zone       |
| `speed_zone_exceed.mp3`  | Beep continuo al exceder el límite de velocidad  |
| `veh_stopped.mp3`        | Alerta fuerte — vehículo detenido adelante       |
| `overtake_alert.mp3`     | Beeps urgentes — vehículo alcanzando por detrás  |
| `sos_alert.mp3`          | Alerta crítica — SOS / accidente                 |

All sounds should be short MP3 clips. The entry sound plays once on zone entry.
The exceed sound loops continuously until speed is reduced below the limit.
