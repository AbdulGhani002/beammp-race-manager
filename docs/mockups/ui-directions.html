What a new skin changes

  • One file. The look lives in app.css. The markup, the Lua and the server never move.
  • Nothing is retested. The 146 interface checks read names, not colours, so they keep passing.
  • It can be swapped later. Picking one now does not lock the server out of the others.

What stays the same either way

  • Every panel drags where you want it and remembers the spot.
  • Clicking off a panel, or Escape, shuts it.
  • Messages count themselves out over ten seconds and go.
  • The clock, the lap bar and the hold stay on screen with every panel shut.
